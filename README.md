Personal portfolio hosted with GitHub Pages.

## Site pages

- `index.html` — introduction, experience, background, and skills.
- `projects.html` — selected projects and coursework.
- `blog.html` — automatically lists posts from the Jekyll `_posts` collection.

## Updating the portfolio

Replace the bracketed prompts in the HTML pages with your content. Duplicate a project card, experience entry, or coursework row to add another item. Replace the sample `#` links with links to public repositories, demos, or write-ups.

To publish a blog post, copy `POST_TEMPLATE.md` into a new `_posts` folder and name the file `YYYY-MM-DD-your-title.md`. Set the post title and date in its YAML front matter, write the article in Markdown, then commit and push. GitHub Pages will render the post and add it to the blog index.

Before publishing, check that linked work, text, images, and data are appropriate to make public.
